Java Escape Room

Five locked rooms. Each program prints a door code — type it here to open the next room. Every room starts from the code you found in the room before.

00:00
First time? Set up VS Code (2 minutes)
  1. Open WPILib VS Code (the desktop shortcut with the year in its name), not a regular VS Code.
  2. Click File → Open Folder, make a new folder called escape-room, and open it. If it asks whether you trust the folder, click Yes.
  3. Click File → New File and name it exactly Escape.java. The capital E matters.
  4. Paste or type the room’s code into that file and save with Ctrl+S (Mac: ⌘+S).
  5. Click the small Run link that appears just above the line with main. The door code prints in the terminal at the bottom of the window.
  6. No Run link? Java support takes a minute to load the first time. Watch the bar at the bottom of the window, then try again.
